# Earth Self-Reproduction Hypothesis（ESRH）
本リポジトリは、地球を「自己複製を志向する惑星」として捉える思想体系  
**ESRH（Earth Self-Reproduction Hypothesis）** の原稿を公開するものです。

本稿は、前稿「HERH（水中心の地球再生産仮説）」を内包しつつ、  
大気・水・生命・技術・宇宙移住といった地球システム全体を  
“地球の自己複製プロセス”として再解釈する試みです。
